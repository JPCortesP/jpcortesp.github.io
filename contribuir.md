Si encontraste un error, una omision o quieres proponer una mejora, puedes contribuir de forma sencilla.

## Como reportar una correccion

1. Abre un issue en GitHub.
2. Explica el error y, si puedes, incluye el enlace de la pagina.
3. Propone el cambio sugerido para acelerar la correccion.

Si esta opcion no aparece en esta vista, usa el repositorio de este blog en GitHub para abrir un issue.
{% endif %}
